KOINE system architecture

A GitHub push becomes a mechanically-derived translation queue. A Gemini fleet on Google ADK proposes candidates; a deterministic core re-checks and seals each one into a per-language hash chain. The model is never on the decision path — swap the backend and the wording changes, never a verdict. Everything runs on Google Cloud Run.

Why the model sits off the decision path

A language model can read the evidence correctly and still reach the wrong conclusion under narrative pressure. So the deterministic engine derives every block's state from hashes alone and seals it before any wording is produced. The fleet's translator and reviewer only produce candidates; the reviewer cannot even approve — promotion is a mechanical re-check.

The test of the boundary: swapping the model backend (or removing it entirely) changes translations that get proposed, never a sealed verdict, a ledger hash, or the gate's exit code. That is the property the dashboard and the CI gate both rely on when they read the same chain.
